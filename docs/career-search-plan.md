# От списка нанимающих к кадровой странице

## Схема

1. **Кто нанимает** — государственный портал Služby zamestnanosti и список работодателей profesia.sk.
2. **Адрес сайта** — с портала («Internetová adresa», домен почты контакта) и со страницы компании на profesia.sk;
   нет там — Wikidata, адрес по названию.
3. **Поисковик по сайту** — обходит сайт компании и находит кадровую страницу.
4. **Чтение** — вакансии с кадровой страницы (адаптеры систем найма; позже — собственные страницы).

Где сейчас (2026-10-12): нанимающих по стране 7 644, сайт есть у 3 699; на эталоне кадровая страница найдена примерно
у 6 из 10 сайтов (прогон 2026-10-08), читается 48. Шаги 1–2 работают; шаг 3 — ядро только «заглядывает» на сайт
(главная, одна кадровая ссылка, пробные адреса); шаг 4 — только системы найма.

## Порядок и правила

- Шаги по номерам; каждый шаг кода — срез с записью в стенограмме (рабочий контракт §0.6).
- Прогоны стенда — по одной команде, только когда без них нет вывода (рабочий контракт §0.6).
- Поисковик соблюдает robots.txt, паузу на сайт и лимит страниц; страницы не хранит — только найденный адрес.
- Выход из шага 1.7 — пороги бизнес-описания §7.4 (сайт верен у ≥ 95 % найденных, кадровая страница обнаружена у
  ≥ 90 % сайтов, где она есть).

## Что не решает этот план

- Компании без сайта (по стране — около половины нанимающих; в основном малые фирмы) — их вакансии с портала.
- Сайты без кадрового раздела.
- Кадровые сайты групп на чужих доменах без ссылки с сайта компании — частично решено пробой кадровых хостов (§89).
