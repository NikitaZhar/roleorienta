# Следующий шаг

Перезаписывается в конце каждого среза. Раздел «Долг» переносится без изменений, пока пункт не
закрыт срезом.

**Последний срез:** §37 — Workday без фасета страны: фильтр по местам страны.

**Порядок (решение владельца, 2026-10-01; технический документ §15).** Сначала охват доводится до
конца, затем 1.5. Полнота охвата — по компаниям: каждое действующее юрлицо страны получает итог
проверки с причиной (бизнес-описание §4.2, §7.3). Процент найденных вакансий не меряется — общего
числа вакансий страны нет.

1. **Стенд после §37 (без кода).** Через час после перезапуска: у AstraZeneca — только публикации в
   Словакии (4), а не 1029.
2. **§38 — SmartRecruiters: потолок страниц у крупных компаний** (JYSK, Eurofins — `PAGE_LIMIT`,
   словацкие вакансии дальше 50-й страницы теряются).
3. **§39 — итог проверки с причиной у каждой компании** (показатели бизнес-описания §7.3 по
   причинам): сколько компаний без сайта, без кадровой страницы, с неподдерживаемым форматом — и
   какой системой найма. Это и есть недостающий протокол этапа 0.
4. **Срезы охвата по числам §39** — от самой крупной причины потерь к меньшей (форматы, способы
   поиска сайта, скорость проверки досок). Критерий остановки — первичный обход Словакии завершён
   (итог у всех юрлиц), крупнейшие части каждой причины разобраны; дальше — по решению владельца.
5. **1.5 до конца:** список, сведения, отметки; SPA.

**Снято с плана (2026-10-01):** вход «филиалы иностранных компаний» — в RPO их около 1250, в основном
мелкие чешские фирмы; крупные работодатели (Dell, Accenture, Cisco) — словацкие s.r.o., их пробел —
поиск сайта (§39 покажет объём). SAP SuccessFactors и отдельный сервис проверки досок — только если
их покажут числа §39. Следующая страна — по порядку бизнес-описания §4.1 и решению владельца
после полного цикла на Словакии.

## Долг

1. **Хранилище снимков — заменить архивный образ MinIO** (§18). `bitnamilegacy/minio` не
   обновляется и может исчезнуть из реестра; тогда не поднимутся CI и `docker compose`. Замена —
   поддерживаемое S3-совместимое хранилище (кандидаты: SeaweedFS, Garage, RustFS) в
   `docker-compose.yml` и `TestcontainersConfiguration`; поправить «локально MinIO» в техническом
   документе и README. Код (AWS SDK) не меняется. Крайний срок — до подэтапа развёртывания
   (`ops-check`, технический документ §12) или сразу, если образ пропадёт.
2. **Срок хранения снимков и очистка сирот** (технический документ §16.10; §23). Снимки хранятся
   бессрочно, объекты без ссылки в БД не удаляются. Срока в §17 нет — задаёт владелец. Крайний
   срок — до эксплуатационной проверки (1.10).

3. **Вынесено из 1.5 (решение владельца, §31):** экран показателей — в 1.10 (нужна
   `CoreMetricDaily`); ручное добавление компании — 1.9; причина пустоты «обработано X из Y» — 1.6
   (первичный обход по странам); `ETag`/`If-None-Match` на списке и сведениях и описание API в
   OpenAPI (springdoc) — после ядра (технический документ §8). Крайний срок — до критерия
   готовности этапа 1 (технический документ §15).

**Правила работы:** срез — одна задача, без полировки и расширения; сборку и коммит делает
владелец; счётчик до аудита — в шапке `docs/project-notes.md`.
