# Следующий шаг

Перезаписывается в конце каждого среза.

**Последний срез:** §13 — robots.txt (подэтап 1.2).

**Следующий срез:** §14 — адаптер schema.org `JobPosting`: разметка JSON-LD на страницах вакансий
сайта компании (технический документ §5). С кадровой страницы берутся только ссылки на страницы
вакансий; потолок числа страниц — настройка; упор в потолок — неполное чтение.

**Затем по порядку** (расхождения из аудита §11):
1. `SourceSnapshot` (снимки ответов в S3), `CrawlRun`, `VacancyRevision`.
2. ArchUnit и правило «XML только через `SafeXml`».
3. Подэтап 1.3 — по техническому документу §15.

**Правила работы:** срез — одна задача, без полировки и расширения; сборку и коммит делает
владелец; счётчик до аудита — в шапке `docs/project-notes.md`.
