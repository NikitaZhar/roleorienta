# План работ roleorienta (Этап 1)

**Цель Этапа 1** — как можно раньше проверить самую рисковую гипотезу: приложение само, без
ручных списков, находит реальных работодателей и их карьерные ленты и честно показывает вакансии,
которых нет на сравниваемых площадках. Охват — по вендор-адаптерам ATS, включая энтерпрайз
(Workday, SuccessFactors, SmartRecruiters; ADR-17). Магистраль доставки (RabbitMQ + outbox, ADR-10)
построена и не переделывается — закрываются только дефекты, мешающие реальному прогону.

Этап 0 (проверка источника и рынка) закрыт — [протокол Этапа 0](stage-0-protocol.md).

## Приоритет A — ядро гипотезы

- [x] **A1. Автоматический вход обнаружения** — индекс Common Crawl `*.myworkdayjobs.com`
      (CT для Workday непригоден), включён (§55, §72–§74).
- [ ] **A2. Принадлежность доски работодателю в гейте.** Workday — сделано: описание страницы
      доски называет тенант, нет признаков агентства, иначе ручная проверка (§79). Другие
      провайдеры — вместе с A4.
- [ ] **A3. Идентичность работодателя и дедуп.** Внутри провайдера — сделано: имя из описания
      доски, одна компания на (провайдер, тенант), V28 (§80), дубли объединены V30 (§85). Между
      провайдерами — открыто.
- [ ] **A4. Адаптеры вендоров.** Workday — сделано (§50–§53, §65–§70); Personio (малый и
      средний бизнес DACH, публичная XML-лента) — адаптер и вход Common Crawl (§91); Greenhouse —
      адаптер есть, во вход не включён; Lever — разрешено, адаптера нет; SuccessFactors,
      SmartRecruiters (Posting API требует ключ) — открыто.
- [ ] **A5. Покрытие площадками** (`CoverageAssessment`, «только с сайта / и там, и там / не
      проверено», фильтр в ленте). Австрия — karriere.at (§81–§83, §86); её условия запрещают
      автоматическое чтение (§90) — проверка выключена (§91). Словакия — profesia.sk запрещает так
      же (§90). Владелец: метка «скрытая» мало что добавляет — оставить или убрать A5 целиком
      (код, поле `coverage` в API, фильтр) — решение владельца.
- [ ] **A6. Снимки `SourceSnapshot` (S3) + привязка требования к снимку** (объяснимость
      «навык → формулировка → снимок», ADR-8). Хранилище выбрано: MinIO локально + AWS SDK v2.
- [x] **A7. Дайджест + email** — ежедневно, SMTP (локально Mailpit), доставка с состоянием,
      V31 (§88). Не вошло: частота по выбору пользователя, «вероятно закрытые».

  оставить выключенным.
- **Ленты Workday** — запрета не найдено, серая зона; решить, отдавать ли полный текст вакансии в API.
- **SPA/онбординг** (непустой первый экран, §14) — вне backend-репозитория; проверять гипотезу с
  пользователем без интерфейса нельзя. Планируется отдельно.
