# Документация roleorienta

Источник истины по продукту и правилам разработки. Документы версионируются
вместе с кодом: изменения архитектуры (например, ADR) идут одним PR с кодом.

- [Бизнес-ТЗ](business-requirements.md) — продукт с точки зрения бизнеса: что и зачем.
- [Технический документ](technical-design.md) — архитектура, стек, модель данных, этапность, ADR.
- [Рабочий контракт](working-contract.md) — правила работы с кодом (боевая инструкция).
