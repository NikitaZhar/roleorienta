# Документация roleorienta

Источник истины по продукту и правилам разработки. Документы версионируются
вместе с кодом: изменения архитектуры (например, ADR) идут одним PR с кодом.

- [Бизнес-ТЗ](business-requirements.md) — продукт с точки зрения бизнеса: что и зачем.
- [Технический документ](technical-design.md) — архитектура, стек, модель данных, этапность, ADR.
- [Рабочий контракт](working-contract.md) — правила работы с кодом (боевая инструкция).
- [Регламент сессии](session-protocol.md) — обязательный порядок работы ассистента: старт сессии, срез, сдача, аудит каждые 10 срезов, проверки CI.
- [Текущее состояние](current-state.md) — как устроен проект сейчас (2–3 страницы) и счётчик срезов до аудита, реестр правовых оснований источников.
- [План работ](roleorienta-plan-korrektirovka.md) — текущий список задач Этапа 1 по приоритетам.
- [Протокол Этапа 0](stage-0-protocol.md) — закрытый протокол проверки источника (Workday) и рынка (SK/AT).
- [Разбор каркаса](project-notes.md) — конструкции и файлы репозитория с пояснениями и ссылками на документацию.
