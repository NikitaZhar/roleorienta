# Roleorienta

Приложение ищет открытые вакансии по условиям пользователя (страны, одна или несколько позиций, формат работы):
само находит компании выбранных стран и их каналы вакансий — кадровые страницы и государственный
портал вакансий (вместе с объявлениями площадок), — собирает и обновляет вакансии (у каждой компании из одного,
лучшего канала) и выдаёт пользователю подходящие порциями.

Документы: [бизнес-описание](docs/roleorienta-Business%20description.md),
[технический документ](docs/technical-design.md), [рабочий контракт](docs/working-contract.md),
[стенограмма проекта](docs/project-notes.md).

## Архитектура

Два приложения Spring Boot на общей PostgreSQL:

| Модуль | Роль |
|---|---|
| `job-api` | REST API и пользовательские сценарии; владеет схемой БД (Flyway) |
| `job-worker` | Фоновая работа: планировщик, outbox → RabbitMQ, общий сбор, проходы выдачи |
| `web` | SPA (React, TypeScript, Vite): вход; условия поиска; накопленный список, сведения о вакансии, отметка «не подходит» и отмеченные. Собирается Maven-ом: Node.js скачивается в `web/node` |

## Стек

Java 21, Spring Boot 4.1.1, PostgreSQL 16, Flyway, RabbitMQ 4, MinIO (S3), Apache HttpClient 5, Jsoup, Maven,
JUnit 5 + Testcontainers, Checkstyle, GitHub Actions; SPA — React 19, TypeScript, Vite (Node.js скачивает
frontend-maven-plugin, ставить не нужно).

## Запуск локально

Нужны JDK 21, Maven, Docker.

```bash
docker compose up -d                       # PostgreSQL :5433, RabbitMQ :5672, MinIO :9000
mvn -B -ntp verify                         # Checkstyle, компиляция, тесты (Testcontainers), сборка SPA
mvn -pl job-api spring-boot:run            # http://localhost:8080/actuator/health
mvn -pl job-worker spring-boot:run         # http://localhost:8081/actuator/health
```

SPA в разработке (после `mvn verify`; job-api запущен на :8080):

```bash
mvn -pl web frontend:npm -Dfrontend.npm.arguments="run dev"   # http://localhost:5173, /api — на job-api
```

Настройки подключения — переменные окружения (`DB_URL`, `DB_USERNAME`, `DB_PASSWORD`,
`RABBITMQ_HOST`, `RABBITMQ_USERNAME`, `RABBITMQ_PASSWORD`, `SERVER_PORT`; cookie сессии только по HTTPS —
`SESSION_COOKIE_SECURE=true` (при развёртывании); снимки в MinIO — `S3_ENDPOINT`,
`S3_BUCKET`, `S3_ACCESS_KEY`, `S3_SECRET_KEY`); значения по умолчанию
совпадают с `docker-compose.yml`.
